# New species-history application fixtures

Global and country quantities were independently recalculated from the unchanged
v0.6 group-year numerical coefficients, the 731-code mapping, and the updated species
history. These are regression targets, not native-R outputs or independent empirical
validation of the feeding assumptions.

They apply to input_md5.csv's exact source bytes, 1973–2023 coefficients, early_policy
hold, and both recent-composition options enabled. Other configurations still receive
structural/mass-balance checks, but do not have these same expected demand totals.

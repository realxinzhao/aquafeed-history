# Data and code rights

The default publication destination is a **private** repository under the user's account. No third-party papers, font files, credentials, or access tokens are included.

- Production CSVs are supplied by the user. Their original source/data terms continue to apply.
- Numerical literature tables are curated transcriptions with source URLs, table/page locations, and notes. This project does not grant new rights to the underlying publications or company reports.
- Mapping and modeling assumptions are research inputs, not authoritative taxonomic or industry inventories.
- No open-source license for this project's code has been selected on the user's behalf. Choose a code license and review redistribution/data terms before making the repository public.
- Derived files inherit the limitations and attribution requirements of their inputs. Private repository status does not itself resolve third-party licensing.

Do not commit full downloaded PDFs, tokens, `.Renviron`, local credentials, or personal R session files. They are excluded by the supplied `.gitignore`.
